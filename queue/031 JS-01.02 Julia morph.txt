Same rule, z → z² + c, but now fix c and colour each starting point z. That's a Julia set. Walk c from 0 to −0.6: one crumpled blob. Walk it into the period-3 bulb: Douady's rabbit, three ears on every blob. Step c outside the Mandelbrot set and the whole thing shatters into dust. The theorem behind it (Fatou and Julia, 1919): the Julia set is one piece exactly when the orbit of 0 stays bounded. The Mandelbrot set is a map of every Julia set.
