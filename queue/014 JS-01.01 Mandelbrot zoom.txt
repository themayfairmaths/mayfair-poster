One line of algebra: z → z² + c. Each pixel is a number c. Start at z = 0 and keep squaring and adding c. If |z| ever passes 2 it flies off to infinity; colour the pixel by how fast. If it never escapes, the pixel is in the Mandelbrot set (black). c = 0.24 stays small for ever, c = 0.26 escapes after 29 steps: the edge is that sharp. Then zoom ×300 into seahorse valley and ×100,000 beyond: the boundary never runs out of detail (it has fractal dimension 2, Shishikura 1998).
